# Лабораторная работа №2 — Git и GitHub

Учебный проект на Python для практики работы с Git и GitHub. В репозитории отрабатываются коммиты, ветки, Pull Request, разрешение конфликтов слияния, теги и релизы.

## Требования

- Git для клонирования репозитория.
- Python 3 для запуска скрипта.

## Запуск

```bash
git clone https://github.com/rusv-zgu/laba2.git
cd laba2
python src/main.py
```

Если репозиторий уже клонирован, выполни `python src/main.py` из его корневой папки.

## Что делает программа

Скрипт [`src/main.py`](src/main.py) выводит приветствие и две строки с арифметическими выражениями. Все три строки заданы в коде и выводятся через `print()`.

```text
Hi, World!
2+2=5
2*2=67
```
